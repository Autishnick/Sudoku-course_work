# 🧩 Sudoku Frontend

Клієнтська частина вебзастосунку Sudoku, розроблена на базі сучасного вебстеку.

## 🛠 Стек технологій

- **Фреймворк:** React 19
- **Збирач:** Vite 7
- **Управління станом:** React Context API + Custom Hooks (`useGame`)
- **HTTP-клієнт:** Axios
- **Стилізація:** Модульний CSS (Grid, Flexbox, Transitions)

## 🌟 Основні можливості інтерфейсу

- **Інтерактивна дошка 9x9:** швидке введення цифр із клавіатури, навігація за допомогою стрілок (`ArrowUp`, `ArrowDown`, `ArrowLeft`, `ArrowRight`).
- **Валідація в реальному часі:** підсвічування конфліктуючих клітинок та некоректних ходів.
- **Режими гри:**
  - Генерація нової гри (Easy, Medium, Hard).
  - Режим «Створити свій пазл» із попередньою клієнтською та серверною валідацією.
- **Управління станом гри:** збереження прогресу під унікальним іменем, завантаження та видалення збережень.
- **Звітність:** можливість перегляду HTML-звіту та завантаження офіційного PDF-звіту з результатами.

## 🚀 Запуск проєкту локально

```bash
# Встановлення залежностей
npm install

# Запуск dev-сервера (порт 5173 з проксі на бекенд)
npm run dev

# Збірка продакшн-версії
npm run build
```
